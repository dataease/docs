    更新日志¶

    1 版本说明¶

    版本号说明： 像其它优秀开源项目一样，DataEase 将保持每月发布一个新的功能版本，功能版本中如遇较为紧急或严重的 Bug，将及时推出 Bug 修复的小版本。
    DataEase 版本号命名规则为： v 大版本.功能版本. Bug 修复版本，示例如下：

    • v3.0.1 是 v3.0.0 之后的 Bug 修复版本
    • v3.1.0 是 v3.0.0 之后的功能版本

    插件管理 支持数据源插件和图表插件
    水印管理 支持对仪表板和数据大屏进行水印设置
    安全管理 支持配置全局 MFA 设置，用于控制 MFA 的强制生效范围
    系统 API（X-Pack） 系统 API 支持 API Keys 管理
    提供完善的 API 接口及文档
