# 电子表格

## 1 功能概述

!!! Abstract ""
    【电子表格】是 DataEase v3.0.0 起新增的功能模块，用于在线创建、编辑和发布电子表格。用户可以在工作台中直接进入电子表格模块，通过连接已有数据源，以表格的形式展示和分析数据。

    - 支持创建文件夹，对电子表格进行分类管理；
    - 支持明细表、汇总表两种表格类型，支持在表格中插入明细表 / 汇总表对象；
    - 支持设置表格样式、数据字段、过滤条件等；
    - 支持发布 / 下线，发布后可被其他用户查看；
    - 支持绑定数据集，支持定时刷新数据；
    - 支持插入图表（柱状图、折线图、饼图等 25+ 类型）与查询控件，实现条件查询与图表联动；
    - 编辑器提供与 Excel 高度一致的单元格编辑能力（字体、对齐、边框、合并、数字格式、公式等）。

【图：电子表格模块首页全貌】

!!! Abstract ""
    **与 Excel 的关系**：编辑器的单元格编辑能力基于 Univer 引擎实现，与 Excel 重合度约 90%，使用过 Excel 的用户可以零成本上手。差异主要体现在两端：Excel 独有而本产品未提供的能力（VBA 宏、原生数据透视表、复杂条件格式规则等），以及本产品独有而 Excel 没有的数据中台能力（绑定数据集、手动 / 定时刷新、发布 / 下线共享、查询控件与图表联动、血缘分析等），完整对照见第 9.1 节。

## 2 快速上手

!!! Abstract ""
    本节以「制作一张可发布的月度销售明细表」为例，用 6 步完成从新建到发布的完整流程，帮助新用户快速了解电子表格的核心操作路径。

!!! Abstract ""
    **第 1 步：进入电子表格模块**

    - 在工作台顶部一级菜单点击【电子表格】，进入模块首页。

!!! Abstract ""
    **第 2 步：新建电子表格**

    - 点击左侧资源栏标题旁的【新建】按钮，选择【新建电子表格】，创建后自动进入表格编辑界面。
    - 提示：需要组织多个表格时，可先【新建文件夹】进行分类管理。

!!! Abstract ""
    **第 3 步：绑定数据**

    - 在编辑界面的数据配置区选择数据源与数据集，完成表格的数据绑定。

!!! Abstract ""
    **第 4 步：拖拽字段与设置样式**

    - 将数据集字段拖拽至行、列、值区域；
    - 设置表头样式、边框、行高列宽、数字格式等；
    - 支持设置过滤条件（行权限、时间过滤、字段过滤）。

!!! Abstract ""
    **第 5 步：插入图表与查询控件（可选）**

    - 通过工具栏【插入】下拉插入图表对象，选择图表类型并绑定数据区域；
    - 插入查询控件，配置查询字段，实现条件查询与图表联动（详见第 5 章与第 7 章）。

!!! Abstract ""
    **第 6 步：预览、保存并发布**

    - 点击【预览】查看最终展示效果，确认无误后【保存】；
    - 点击【发布】上线，其他用户即可在电子表格列表中查看。

!!! Abstract ""
    **避坑提示**

    - 未发布的表格在列表中显示「发布后可查看」，其他用户无法查看，需先发布；
    - 编辑过程中随时【保存】，避免内容丢失；发布状态不会因再次编辑而丢失。

## 3 创建电子表格

!!! Abstract ""
    步骤一：在工作台顶部一级菜单点击【电子表格】进入模块首页。

!!! Abstract ""
    步骤二：点击左侧资源栏标题旁的【新建】按钮，可选择新建电子表格或新建文件夹。

    - 新建电子表格：创建后进入表格编辑界面；
    - 新建文件夹：用于组织和管理多个电子表格。

!!! Abstract ""
    步骤三：在编辑界面中配置表格内容，包括：

    - **数据配置**：选择数据源与数据集，绑定表格字段；
    - **字段拖拽**：将数据集字段拖拽至行、列、值区域；
    - **表格样式**：设置表格边框、行高、列宽、表头样式等；
    - **过滤条件**：设置行权限、时间过滤、字段过滤等。

## 4 编辑器工具栏说明

电子表格编辑器采用类 Excel 的界面布局：顶部为标题栏与操作区，其下为工具栏（分多排），中间为单元格编辑区，右上角提供预览 / 保存 / 发布按钮，底部为工作表标签与缩放控制。

【图：电子表格编辑器界面全貌】

### 4.1 顶部操作区

| 按钮 | 功能说明 |
| --- | --- |
| 返回（←） | 返回上一级界面，退出当前编辑 |
| 预览 | 预览当前表格最终展示效果（只读模式） |
| 保存 | 保存当前编辑内容 |
| 发布 | 将表格发布上线，供其他用户查看 |

**典型操作**：编辑完成后点击【预览】检查效果 → 确认无误点击【保存】→ 需要共享时点击【发布】。

| 格式刷 | 复制单元格格式并应用到其他区域 |

## 5 图表制作

### 5.1 选图原则

插入图表前，先想清楚要展示什么信息，再选择图表类型，避免"为了好看而复杂"：

| 你想展示什么 | 推荐图表类型 |
| --- | --- |
| 对比（谁大谁小、排名） | 柱状图 / 条形图 |
| 趋势（随时间的变化） | 折线图 |
| 构成（各部分占整体比例） | 饼图 |
| 分布（数据集中在哪些区域） | 散点图 |

!!! Abstract ""
    建议一个图表只讲一件事：如需同时展示多个主题，可拆分为多张图表，避免在一张图中堆叠过多数据系列导致难以阅读。

### 5.2 图表类型

电子表格支持 25+ 种图表类型，覆盖柱状图、折线图、饼图等常用类型（具体以编辑器【插入 → 图表】面板实际提供为准）。

### 5.3 制作步骤

!!! Abstract ""
    步骤一：选中需要生成图表的数据区域。

!!! Abstract ""
    步骤二：点击工具栏【插入】→【插入图表】。

!!! Abstract ""
    步骤三：在图表类型面板中选择图表类型（柱状图、折线图、饼图等）。

!!! Abstract ""
    步骤四：图表插入后，可调整位置与大小；绑定的数据区域变化时，图表数据同步更新。

!!! Abstract ""
    步骤五（可选）：插入查询控件，使图表随查询条件联动刷新（详见第 7 章）。

## 6 表格类型

### 6.1 明细表

!!! Abstract ""
    **预期效果**：明细表以逐行记录的方式展示数据集的明细数据，支持字段拖拽排序、单元格样式设置、合并单元格、导出等能力。

    **制作步骤**：

    - 在编辑器中点击【插入 → 插入明细表】，在表格中嵌入明细表对象；
    - 将数据集字段拖拽至明细表区域，配置展示列；
    - 按需设置单元格样式、合并单元格、行列冻结。

### 6.2 汇总表

!!! Abstract ""
    **预期效果**：汇总表支持将字段拖拽至行区、列区和值区，对数据进行汇总分析，支持合计、小计等计算能力。

    **制作步骤**：

    - 在编辑器中点击【插入 → 插入汇总表】，在表格中嵌入汇总表对象；
    - 将维度字段拖拽至行区 / 列区，指标字段拖拽至值区；
    - 设置汇总方式与样式，按维度对指标进行聚合统计。

!!! Abstract ""
    - 明细表与汇总表均支持**行列冻结**，滚动查看长表时固定表头；
    - 明细表支持显示图片、单元格合并。

## 7 查询控件与图表联动

### 7.1 功能概述

!!! Abstract ""
    **查询控件**是 DataEase 电子表格的特色能力（工具栏右侧），用于为表格配置动态查询条件。当表格中插入了图表时，查询控件的筛选会同步驱动图表数据更新，实现「控件选条件 → 表格过滤 → 图表联动刷新」的联动效果，无需重新配置图表。

### 7.2 配置步骤

- **插入查询控件**：点击工具栏【查询控件】按钮，为表格添加查询控件；
- **配置查询字段**：按需配置查询字段与条件类型（文本下拉、时间范围、数字区间等）；
- **调整布局**：控件插入后可拖动调整位置。

### 7.3 联动效果

- 在控件中选择或输入查询条件后，表格数据即时刷新，仅展示满足条件的数据；
- 已插入的图表随筛选条件同步更新，实现「控件选条件 → 表格过滤 → 图表联动刷新」的联动链路。

### 7.4 常见问题

- **图表不随查询条件变化？** 请确认查询控件已配置查询字段，且图表绑定的是被查询控件过滤的数据区域；
- **查询后表格为空？** 表示当前查询条件下没有满足条件的数据，可清空或调整查询条件后重试。

## 8 发布与数据刷新

### 8.1 发布与分享

!!! Abstract ""
    电子表格编辑完成后，点击【发布】按钮即可将表格上线。已发布的电子表格支持：

    - 在电子表格列表中以只读模式查看；
    - 通过【取消发布】使表格下线；
    - 通过【恢复发布】重新上线历史版本；
    - 对已发布表格进行重命名、移动、删除等管理操作。

### 8.2 数据刷新

!!! Abstract ""
    绑定数据集的电子表格支持两种刷新方式：

    - **手动刷新**：在编辑界面点击刷新按钮，即时拉取最新数据；
    - **定时刷新**：配置刷新频率，系统按设定的时间周期自动刷新表格数据。

## 9 与 Excel 的差异对照及常见问题

### 9.1 能力差异对照

| 能力维度 | Excel | DataEase 电子表格 |
| --- | --- | --- |
| 单元格编辑（字体 / 对齐 / 边框 / 合并 / 数字格式 / 公式） | ✅ | ✅（Univer 引擎，重合度约 90%） |
| 插入明细表 / 汇总表对象 | ❌ | ✅（DataEase 特色，可绑定数据集） |
| 查询控件与图表联动 | ❌（需公式或切片器手动搭建） | ✅（控件选条件，表格与图表同步刷新） |
| 绑定数据集并定时刷新 | ❌（本地文件） | ✅（支持手动 / 定时刷新） |
| 发布 / 下线共享 | ❌ | ✅（发布后可被其他用户查看） |
| VBA 宏 | ✅ | ❌ |
| 原生数据透视表 | ✅ | ❌（可用汇总表替代） |
| 复杂条件格式规则 | ✅ | ❌（仅支持基础条件格式） |

### 9.2 常见问题（FAQ）

- **表格在列表中显示「发布后可查看」？** 表示该表格尚未发布，其他用户无法查看；进入编辑后点击【发布】即可上线。
- **长表滚动时表头消失？** 使用【冻结窗格】固定首行 / 首列（见 4.7）。
- **数据变化后表格如何更新？** 绑定数据集后支持手动 / 定时刷新（见 8.2）；配合查询控件可随条件动态过滤（见第 7 章）。
- **如何规范单元格输入内容？** 使用【数据有效性】限定输入范围（列表、数值区间、日期等），配合【单元格保护】防止误编辑（见 4.10）。
- **打开表格是否需要安装 Office？** 不需要，电子表格为在线功能，在工作台浏览器中直接使用。
