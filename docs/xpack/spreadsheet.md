# 电子表格

## 1 功能概述

!!! Abstract ""
    【电子表格】是 DataEase v3.0.0 起新增的功能模块，用于在线创建、编辑和发布电子表格。用户可以在工作台中直接进入电子表格模块，通过连接已有数据源，以表格的形式展示和分析数据。

    - 支持创建文件夹，对电子表格进行分类管理；
    - 支持明细表、透视表两种表格类型；
    - 支持设置表格样式、数据字段、过滤条件等；
    - 支持发布 / 下线，发布后可被其他用户查看；
    - 支持绑定数据集，支持定时刷新数据；
    - 编辑器提供与 Excel 高度一致的单元格编辑能力（字体、对齐、边框、合并、数字格式、公式等）。

【图：电子表格模块首页全貌】

## 2 创建电子表格

!!! Abstract ""
    步骤一：在工作台顶部一级菜单点击【电子表格】进入模块首页。

!!! Abstract ""
    步骤二：点击左侧资源栏标题旁的【新建】按钮，可选择新建电子表格或新建文件夹。

    - 新建电子表格：创建后进入表格编辑界面；
    - 新建文件夹：用于组织和管理多个电子表格。

!!! Abstract ""
    步骤三：在编辑界面中配置表格内容，包括：

    - **数据配置**：选择数据源与数据集，绑定表格字段；
    - **字段拖拽**：将数据集字段拖拽至行、列、值区域；
    - **表格样式**：设置表格边框、行高、列宽、表头样式等；
    - **过滤条件**：设置行权限、时间过滤、字段过滤等。

## 3 编辑器工具栏说明

电子表格编辑器采用类 Excel 的界面布局：顶部为标题栏与操作区，其下为工具栏（分多排），中间为单元格编辑区，右上角提供预览 / 保存 / 发布按钮，底部为工作表标签与缩放控制。

【图：电子表格编辑器界面全貌】

### 3.1 顶部操作区

| 按钮 | 功能说明 |
| --- | --- |
| 返回（←） | 返回上一级界面，退出当前编辑 |
| 预览 | 预览当前表格最终展示效果（只读模式） |
| 保存 | 保存当前编辑内容 |
| 发布 | 将表格发布上线，供其他用户查看 |

### 3.2 插入与编辑

| 按钮 | 功能说明 |
| --- | --- |
| 插入（+） | 下拉选择插入行、列、图表、形状等对象 |
| 撤销 / 重做 | 撤销或恢复上一步操作 |
| 格式刷 | 复制单元格格式并应用到其他区域 |
| fx 函数 | 插入或编辑函数公式 |
| 取消（×）/ 确认（√） | 编辑栏中取消 / 确认当前输入 |

### 3.3 字体与文本格式

| 按钮 | 功能说明 |
| --- | --- |
| 字体下拉框（默认 Arial） | 切换字体样式 |
| 字号下拉框（默认 11） | 设置字号大小 |
| 加粗（B）/ 斜体（I） | 文本加粗 / 斜体 |
| 中划线（S）/ 下划线（U） | 添加删除线 / 下划线 |
| 字体颜色（A+色条） | 设置文本颜色 |
| 填充颜色（油漆桶） | 设置单元格背景填充色 |

### 3.4 对齐、边框与合并

| 按钮 | 功能说明 |
| --- | --- |
| 水平对齐 | 左对齐 / 居中 / 右对齐 |
| 垂直对齐 | 顶端对齐 / 垂直居中 / 底端对齐 |
| 边框（下拉） | 设置单元格边框样式（全边框、外边框、绘制边框、斜线等） |
| 合并单元格（下拉） | 合并 / 取消合并、合并后居中、跨行 / 跨列合并 |

### 3.5 数字格式

| 按钮 | 功能说明 |
| --- | --- |
| 数字格式（默认常规） | 切换数值、文本、日期、时间、百分比、货币等格式 |
| 百分比格式（%） | 快捷将数字设为百分比显示 |
| 货币格式（¥） | 快捷将数字设为人民币货币样式 |
| 增加 / 减少小数位数 | 调整数字显示的小数位数 |

### 3.6 数据处理与公式

| 按钮 | 功能说明 |
| --- | --- |
| 自动求和（Σ） | 快速对选中区域求和 |
| 排序（A↑Z） | 对选定区域升序 / 降序排列 |
| 筛选（漏斗） | 按条件过滤数据 |
| 查询控件 | 插入查询控件，按条件动态查询 / 过滤表格数据（DataEase 特色能力） |
| 条件格式 | 对单元格按规则应用条件格式 |

### 3.7 对象插入与视图

| 按钮 | 功能说明 |
| --- | --- |
| 插入链接 | 插入超链接 |
| 插入图片 | 向工作表插入图片 |
| 插入工作表 | 新增工作表标签页 |
| 批注 | 为单元格添加批注 |
| 冻结窗格 | 冻结行 / 列，滚动时固定表头或首列 |
| 查找（放大镜） | 在表格中查找 / 替换内容 |
| 软键盘（键盘图标） | 调出虚拟键盘辅助输入 |

### 3.8 单元格编辑栏与状态区

| 元素 | 功能说明 |
| --- | --- |
| 地址框（如 C1） | 显示当前选中单元格地址，支持输入跳转 |
| 公式栏（fx 区域） | 显示 / 编辑当前单元格内容或公式 |
| 底部工作表标签 | 切换 / 管理多个工作表 |
| 底部缩放 | 调整页面显示缩放比例 |

!!! Abstract ""
    **与 Excel 的关系**：编辑器的基础单元格编辑能力与 Excel 高度重合（Univer 引擎实现，重合度约 90%）。差异主要体现在两端：

    - Excel 独有而本产品未提供的：VBA 宏、原生数据透视表、完整图表能力、复杂条件格式规则等；
    - 本产品独有而 Excel 没有的：绑定数据集、手动 / 定时刷新、发布 / 下线共享、查询控件、血缘分析等数据中台能力。

## 4 表格类型

### 4.1 明细表
!!! Abstract ""
    明细表以逐行记录的方式展示数据集的明细数据，支持字段拖拽排序、单元格样式设置、合并单元格、导出等能力。

### 4.2 透视表
!!! Abstract ""
    透视表支持将字段拖拽至行区、列区和值区，对数据进行汇总分析，支持合计、小计等计算能力。

## 5 发布与分享

!!! Abstract ""
    电子表格编辑完成后，点击【发布】按钮即可将表格发布。已发布的电子表格支持：

    - 在电子表格列表中以只读模式查看；
    - 通过【取消发布】使表格下线；
    - 通过【恢复发布】重新上线历史版本；
    - 对已发布表格进行重命名、移动、删除等管理操作。

## 6 数据刷新

!!! Abstract ""
    绑定数据集的电子表格支持两种刷新方式：

    - **手动刷新**：在编辑界面点击刷新按钮，即时拉取最新数据；
    - **定时刷新**：配置刷新频率，系统按设定的时间周期自动刷新表格数据。
