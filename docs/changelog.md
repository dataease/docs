# 更新日志

## 1 版本说明

!!! Abstract ""
    **版本号说明：** 像其它优秀开源项目一样，DataEase 将保持每月发布一个新的功能版本，功能版本中如遇较为紧急或严重的 Bug，将及时推出
    Bug 修复的小版本。  
    **DataEase 版本号命名规则为：** v 大版本.功能版本. Bug 修复版本，示例如下：

    - v3.0.1 是 v3.0.0 之后的 Bug 修复版本
    - v3.1.0 是 v3.0.0 之后的功能版本

## 2 更新内容

### v3.1.0
2026年9月24日

!!! info "漏洞修复 (Security Fixes)"

    - fix: 修复 DataEase 数据引擎配置接口 JDBC URL 注入导致远程代码执行（RCE）的漏洞；
    - fix: 修复 DataEase 数据源 Schema 获取接口（getSchema）JDBC URL 存在命令执行的漏洞；
    - fix: 修复 DataEase 引擎库建表 DDL 列名未转义导致远程代码执行（RCE）的漏洞；
    - fix: 修复特定查询业务场景下 SQL 注入仍可被利用的漏洞；
    - fix(X-Pack): [分享管理]修复分享链接 Ticket 设置未校验创建者导致的安全漏洞；
    - fix(X-Pack): [用户管理]修复 MFA（多因素认证）二维码未授权访问的安全漏洞。
