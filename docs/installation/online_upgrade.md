
!!! Abstract ""
	如果您的服务器可以访问互联网，可以通过以下命令直接升级 DataEase 至最新版本。

	```sh
	# 升级至最新版本
	dectl upgrade
	# 查看 DataEase 状态
	dectl status
	```

	**注意：升级前做好数据库的备份工作是一个良好的习惯，可参考[备份还原](https://dataease.cn/docs/v2/installation/backup_faq/)。**

	**插件兼容性提醒：如果您使用的是企业版并已安装插件，DataEase 升级后请前往[应用商店](https://apps.fit2cloud.com/dataease)下载最新插件，完成插件更新后重启 DataEase。若继续使用旧版插件，涉及该插件的功能可能会报错或无法正常使用。**
